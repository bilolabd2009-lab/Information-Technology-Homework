## Вопросы к Заказчику по содержанию

Раздел 2 ТЗ запрещает публиковать цены и названия, которых в нём нет. Поэтому:

- **Меню** — на сайте только 7 позиций с ценами из ТЗ, а нужно не меньше 20. В разделе «Чай» позиций нет. Нужен полный список меню с ценами.
- **Сорта зерна** (страна, обработка, вкус) и **преподаватели 2 и 3** в ТЗ не указаны — на сайте примерные данные, их нужно подтвердить или заменить.
- **Промокод LATTE10** — размер скидки в ТЗ не указан, на сайте он не назван.

Не получилось:
- Vercel — аккаунт заблокирован, сайт перенесён на GitHub Pages.
- Реальные ВКонтакте, Telegram и YouTube не создавались (с разрешения преподавателя) — только UTM-ссылки и короткие ссылки.
- «Настройки атрибуции» — в русском интерфейсе GA4 (октябрь 2026) такого пункта нет; в записке указаны значения по умолчанию.
- Специальная статистика: в сегменте оповещения GA4 доступен только «Источник первого взаимодействия», а не «Источник сеанса», поэтому условие «сеансы из Instagram упали на 50 %» в точности не задать. Сделано оповещение «0 ключевых событий за день».
- DataLens: селекторы периода, источника и статуса на дашборд не добавлены — не хватило времени до сдачи. Доступ «Просмотр» заказчику не выдан: e-mail неизвестен.
- Данные в отчётах тестовые и малые (27–29.10.2026), выводы предварительные.
