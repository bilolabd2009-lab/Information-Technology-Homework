## Ограничения

- Раздел «Реклама» (пути к ключевым событиям) в России не заполняется: Google Реклама не подключена. Цепочку действий перед заявкой показывает обратный путь (Explore → «ЗЕРНО 7 · Пути», вкладка 2).
- Заявок на 100 сеансов по кампаниям (вкладка «Кампании» дашборда DataLens): barista_dec_2026 — 1 generate_lead на 14 сеансов (≈ 7 на 100); beans_dec_2026 — 0 на 6.
- В GA4 сумма сеансов по строкам (36–37) немного больше итога (34–35): итог GA4 считает уникальные сеансы, а один сеанс может попасть в несколько строк.

## Подсказки к пунктам

- **User acquisition vs Traffic acquisition:** первый считает пользователей по источнику их *первого* визита, второй — каждый *сеанс* по его источнику. Если один человек пришёл сначала из Instagram, потом напрямую — в User acquisition он один раз в instagram, в Traffic acquisition — два сеанса в двух строках.
- **Открытая и закрытая воронка:** в закрытой пользователь должен пройти шаги по порядку с первого; в открытой может войти с любого шага (например, сразу на contacts.html — с form_start). Поэтому на последнем шаге в открытой воронке обычно больше.
- **Расхождение таблицы и GA4:** блокировщики рекламы и отказ от cookie не дают отправить generate_lead, а строка в таблицу записывается; тестовые заявки из редактора Apps Script (testDoPost) тоже есть только в таблице.
