## Состав репозитория

| Путь | Что внутри |
|---|---|
| `index.html` … `404.html` | 9 страниц сайта, статический HTML без сборки |
| `css/style.css` | стили: фирменные цвета #7A4A2A, #F6EFE6, #24211F, шрифты Unbounded и Inter |
| `js/analytics.js` | все вызовы `gtag('event')`, события по атрибутам `data-event` |
| `js/form.js` | форма заявки: проверка, UTM из адреса и sessionStorage, отправка `fetch` |
| `js/main.js`, `quiz.js`, `courses.js`, `menu.js` | меню, тест, свободные места, фильтр меню, галерея, промокод |
| `img/`, `files/` | иллюстрации WebP, OG-картинки, PDF программы и гида |
| `apps-script/Code.gs` | приёмник заявок `doPost(e)` и настройка листа `leads` |
| `docs/` | журнал запросов, события, реестр UTM, изображения, тест, записка, инструкции |
| `screens/` | снимки GA4, UTM, Instagram, отчётов, DataLens, Lighthouse |

Как всё подключить — `docs/setup.md`. Подготовка к приёмке — `docs/acceptance.md`.

## Вопросы к Заказчику по содержанию

Раздел 2 ТЗ запрещает публиковать цены и названия, которых в нём нет. Поэтому:

- **Меню** — на сайте только 7 позиций с ценами из ТЗ, а нужно не меньше 20. В разделе «Чай» позиций нет. Нужен полный список меню с ценами.
- **Сорта зерна** (страна, обработка, вкус) и **преподаватели 2 и 3** в ТЗ не указаны — на сайте примерные данные, их нужно подтвердить или заменить.
- **Промокод LATTE10** — размер скидки в ТЗ не указан, на сайте он не назван.
