# Источники изображений

Все изображения сгенерированы нейросетью Claude Opus 5.5 (Anthropic): модель написала программу на Python (библиотека Pillow), которая нарисовала иллюстрации в фирменных цветах «Зерно 7». Фотостоки не использовались, права третьих лиц не затрагиваются. Формат WebP (OG-картинки — JPEG), каждый файл меньше 300 КБ, у каждого `<img>` заполнен `alt`.
