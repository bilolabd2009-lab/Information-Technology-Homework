## Атрибуция
В текущем интерфейсе GA4 (русская версия, октябрь 2026) в меню «Администратор» нет пункта «Настройки атрибуции». В разделе «Просмотр данных» есть только «Настройки сети» (сети для возврата данных о рекламе), и поиск пункт атрибуции тоже не находит. Поэтому настройки остались значениями GA4 по умолчанию:
- модель для ключевых событий — на основе данных (data-driven); если данных мало, фактически работает последний клик;
- окно ключевых событий для привлечения — 30 дней, для остальных — 90 дней.

Это значения по умолчанию из документации GA4. В интерфейсе ресурса мы их не видели.

## Пользовательское оповещение (специальная статистика)
- Название: «ЗЕРНО 7: за день 0 заявок (ключевые события)».
- Условие: ежедневно, все пользователи, «Ключевые события» меньше или равно 0.
- Уведомление приходит на почту владельца ресурса.
- Зачем: если за день не пришло ни одной заявки, это сигнал проверить форму или трафик.
- По ТЗ условие другое: «Сеансы из Instagram упали больше чем на 50 %». Сегмент в мастере специальной статистики допускает только «Источник, связанный с первым взаимодействием пользователя». Параметра «Источник сеанса» там нет, поэтому условие ТЗ в точности не задать.
- Снимки: `screens/ga4/custom-insight-setup.jpg`, `screens/ga4/custom-insight.jpg`.
